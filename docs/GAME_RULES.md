# Правила игры

Документ описывает поведение серверного движка из [`server.js`](../server.js). Сервер является источником истины для карт, ролей, допустимых действий, завершения партий и ставок.

## Стол и колода

- В игре 2–6 мест. Старт разрешён только когда подключены минимум два участника; начавший игру — создатель комнаты ([`server.js:563-578`](../server.js:563)).
- Доступны колоды на 36 и 52 карты. Любое значение, кроме 52, при создании комнаты превращается в колоду на 36 карт ([`server.js:16-28`](../server.js:16)). В 36-карточной колоде достоинства `6, 7, 8, 9, 10, В, Д, К, Т`; в 52-карточной добавляются `2, 3, 4, 5`.
- Масти: `♠`, `♥`, `♦`, `♣`. Каждая карта имеет уникальный идентификатор из достоинства и масти ([`server.js:16-28`](../server.js:16)).
- При начале раунда каждому участнику раздают шесть карт. До раздачи `deck[0]` записывается в `trumpCard` и его масть становится козырем, но карта не резервируется: раздача может забрать её из колоды. Остаток после раздачи — текущая колода ([`server.js:148-172`](../server.js:148)).
- Если после раздачи колода пуста, масть козыря сохраняется, а `trumpCard` становится `null` ([`server.js:149-152`](../server.js:149), [`server.js:40-42`](../server.js:40)).

## Старшинство и первый ход

- В одной масти карта бьёт карту только при большем индексе достоинства в последовательности выбранной колоды. Козырь бьёт любую некозырную карту. Некозырная карта не бьёт козырь; для двух козырей действует обычное старшинство достоинств ([`server.js:19`, `server.js:96-99`](../server.js:96)).
- Первым атакует игрок с младшим козырем среди розданных карт. Если козырей среди рук нет, первым становится игрок с младшей картой любого достоинства ([`server.js:173-182`](../server.js:173)). При равенстве достоинств выбирается первый найденный игрок в порядке массива мест.
- Первоначальный защитник — следующий активный игрок по кругу после атакующего ([`server.js:85-93`, `server.js:176-182`](../server.js:85)).

## Атака и подкидывание

- Первую карту раунда кладёт только атакующий. После открытия подкидывать могут атакующий и любые другие активные игроки, кроме текущего защитника ([`server.js:590-603`](../server.js:590)).
- Каждая подкидываемая карта должна иметь достоинство, которое уже есть среди атакующих или защитных карт на столе ([`server.js:101-107`, `server.js:596-597`](../server.js:101)). Масть для права подкидывания не важна.
- За один розыгрыш на столе может быть не больше шести атакующих карт ([`server.js:20`](../server.js:20), [`server.js:595`](../server.js:595)). Лимит проверяется по общему числу строк стола.
- Дополнительное ограничение по руке защитника рассчитывается по числу ещё не покрытых строк: новую атаку нельзя добавить, если у защитника карт не больше, чем таких строк ([`server.js:594`](../server.js:594)). Поэтому после покрытия части стола подкидывание может снова стать допустимым, если остаётся место по руке защитника.
- После решения защитника «беру» атакующий всё ещё может подкидывать совпадающие по достоинству карты. Защитник получает стол только после действия атакующего `pass` ([`server.js:651-664`, `server.js:667-670`](../server.js:651)).

## Защита

- Защищаться может только текущий защитник. Карта защиты выбирается для конкретной непокрытой строки либо берётся первая подходящая непокрытая строка, если `targetCardId` не задан ([`server.js:609-617`](../server.js:609)).
- Защитная карта должна пройти `canBeat`: старшая карта той же масти или козырь против некозыря ([`server.js:96-99`, `server.js:614-616`](../server.js:96)).
- Пока есть непокрытая строка, атакующий не может завершить розыгрыш. Когда все строки покрыты, атакующий может сказать `pass` ([`server.js:667-672`](../server.js:667)).
- После успешного отбоя все карты стола переходят в сброс, стол очищается, роли поворачиваются: бывший защитник становится атакующим, следующий активный игрок — защитником ([`server.js:672-681`](../server.js:672)).

## Переводной режим

- Режим комнаты нормализуется к `classic` или `transfer`; перевод доступен только в `transfer` ([`server.js:110-119`, `server.js:627-633`](../server.js:110)).
- Текущий защитник может перевести ход, пока ни одна карта не покрыта, только если все атакующие карты имеют одно достоинство и у него есть выбранная карта этого достоинства ([`server.js:631-642`](../server.js:631)).
- Следующий защитник должен иметь минимум на одну карту больше, чем число карт на столе; иначе перевод запрещён. После перевода текущий защитник становится атакующим, следующий активный игрок — защитником. Исходный атакующий сохраняется в `trickAttackerId` для порядка добора ([`server.js:639-645`, `server.js:239-252`](../server.js:639)).
- Перевод после первого покрытия, после объявления «беру», при разных достоинствах атак или без следующего активного игрока запрещён ([`server.js:627-640`](../server.js:627)).

## Добор и поворот ролей

- После отбоя или взятия сначала выполняется добор, затем выбираются следующие роли ([`server.js:304-321`, `server.js:672-681`](../server.js:304)).
- Добор идёт начиная с атакующего текущего розыгрыша, затем по кругу через активных игроков; текущий защитник добирает последним. Каждый добирает до шести карт, пока колода не пуста ([`server.js:239-252`](../server.js:239)).
- При взятии карты стола добавляются в руку защитника, включая уже покрытые пары; затем выполняется добор ([`server.js:304-311`](../server.js:304)). После отбоя карты стола идут в сброс и в руку не возвращаются ([`server.js:306-311`, `server.js:672-674`](../server.js:306)).
- `trumpCard` очищается только когда колода становится пустой. Пока колода не пуста, это ссылка на карту, которая логически уже входит в колоду; при полном доборе она исчезает ([`server.js:40-42`](../server.js:40)).

## Взятие

- Взять карты может только защитник, если на столе есть хотя бы одна непокрытая карта ([`server.js:651-658`](../server.js:651)).
- Повторно объявить «беру» нельзя. После объявления `takePending` ход возвращается атакующему: он может подкинуть допустимые карты или завершить взятие `pass` ([`server.js:657-664`, `server.js:667-670`](../server.js:657)).
- Если все карты уже покрыты, защитник не может объявить «беру»; атакующий должен завершить розыгрыш отбоя ([`server.js:653-655`, `server.js:670-672`](../server.js:653)).

## Завершение партии

- Когда колода пуста, игрок без карт помечается `finished`. Партия заканчивается, когда остаётся не более одного активного игрока; оставшийся игрок объявляется дураком. Если активных игроков не осталось, результат — ничья ([`server.js:276-288`](../server.js:276)).
- Поэтому последняя карта сама по себе не заканчивает партию: сначала должен быть разрешён текущий стол — отбой или взятие ([`server.js:276-288`, `server.js:667-683`](../server.js:276)).
- Активный игрок, покинувший идущую партию, немедленно становится проигравшим; его карты и стол сохраняются до завершения settlement ([`server.js:523-534`](../server.js:523)). Завершивший игру игрок может отключиться и остаётся в составе участников для статистики и выплаты ([`server.js:523-531`, `server.js:201-227`](../server.js:523)).
- Отключение без выхода сохраняет место. Если все участники остаются отключёнными дольше grace-периода, игра отменяется с возвратом ставок; такая отмена не считается сыгранной партией ([`server.js:762-775`](../server.js:762), функция cleanup/cancel ниже по файлу).

## Ставки и статистика

- Допустимые ставки: `0`, `50`, `100`, `250`, `500`; другое значение становится нулевой ставкой ([`server.js:22-23`, `server.js:113-120`](../server.js:22)). Начальный баланс — 1000.
- Перед стартом каждый подключённый участник должен иметь баланс не меньше ставки. При старте ставка списывается со всех, банк равен ставке, умноженной на число участников ([`server.js:185-199`, `server.js:563-574`](../server.js:185)).
- Проигравший теряет внесённую ставку. Остальные делят банк поровну, а остаток от деления по одной фишке получают первые победители в порядке списка игроков ([`server.js:201-225`](../server.js:201)).
- При ничьей ставки возвращаются; `games` увеличивается, `wins` и `losses` не увеличиваются. При обычном завершении `games` увеличивается всем, а победа начисляется каждому участнику кроме проигравшего ([`server.js:201-227`, `server.js:229-237`](../server.js:201)).
- Активный выход — поражение и обычный settlement. Автоматическая отмена из-за общего отключения — возврат средств без статистики и истории партии (проверено существующими регрессионными тестами).

## Инварианты движка

- В каждый момент каждая карта находится ровно в одном из мест: колода, рука игрока, сброс, атака на столе или защита на столе. Уникальность обеспечивается исходной колодой и удалением карт из руки при действии.
- На столе каждая строка имеет одну карту атаки и не более одной карты защиты; защищённые строки не могут быть покрыты повторно ([`server.js:304-309`, `server.js:612-618`](../server.js:304)).
- `attackerId` и `defenderId` назначаются активным игрокам; после ротации защитник не становится одновременно атакующим ([`server.js:85-93`, `server.js:276-288`](../server.js:85)).
- При незавершённой игре `pot` содержит собранные ставки, а после settlement равен нулю ([`server.js:211-225`](../server.js:211)).
- Снимок игрока содержит его руку, но только размеры рук соперников; сервер отправляет персональный `gameState` для каждого участника ([`server.js:325-411`, `server.js:500-508`](../server.js:325)).

## Спорные и специально зафиксированные случаи


- **«Беру» не является немедленным окончанием розыгрыша.** Это двухфазное решение: защитник объявляет его, атакующий получает возможность подкинуть и только затем подтверждает `pass`.
- **Лимит защиты считается по непокрытым строкам.** Общее число строк ограничено шестью, но проверка вместимости руки защитника использует только строки без защиты.
- **Порядок добора отличается от порядка ролей после розыгрыша.** Добор начинается с атакующего текущего розыгрыша, защитник добирает последним; только затем роли меняются.
- **Карты, оставшиеся у игрока, не делают его проигравшим автоматически.** Проигравшим считается последний активный игрок после того, как пустые руки при пустой колоде помечены завершившимися.
- **В равных случаях нет отдельного правила масти.** При выборе младшей карты используется порядок карт в массиве и первое найденное совпадение; при выборе победителей остаток банка также распределяется по порядку массива игроков.
