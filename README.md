# Дурак Онлайн

Многопользовательский дурак в браузере: лобби с кодом приглашения, живые ходы,
проверка правил на сервере, светлая и тёмная темы.

## Запуск

```bash
npm start
```

Откройте http://localhost:4173. Чтобы позвать друга, создайте лобби и отправьте
ему ссылку вида `http://localhost:4173/?code=XXXXXX` или сам код.

Друзья из локальной сети открывают игру по адресу вашей машины, например
`http://192.168.0.20:4173` (порт 4173 должен быть открыт в файрволе). Обратите
внимание: по HTTP без HTTPS браузер не отдаёт часть API, поэтому приложение
само генерирует идентификаторы клиента и не зависит от `crypto.randomUUID`.

## Что умеет

- Лобби на 2–6 игроков, вход по коду, список открытых игр и счётчик онлайна в
  реальном времени (Server-Sent Events).
- Режимы: подкидной и переводной; колода 36 или 52 карты.
- Сервер сам следит за правилами: очередь хода, козырь, старшинство карт,
  подкидывание только в масть стола и не больше шести карт, перевод хода,
  взятие карт, добор до шести, выход игроков и определение дурака.
- Профиль с именем и цветом аватара, настройки темы, история завершённых партий.
- Перезапуск партии создателем лобби.

## Проверки

Сервер должен быть запущен (`npm start`), затем:

```bash
npm test
```

Сценарии проверяют полную партию до результата, перевод хода, подкидывание
нескольких карт одного достоинства, запрет покрытия неправильной картой,
окно «беру» с возможностью подкинуть ещё, передачу роли хозяина и выход игроков.
